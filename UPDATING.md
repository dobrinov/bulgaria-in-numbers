# Обновяване на данните

Повечето данни излизат веднъж годишно. Достатъчно е проверка на всеки 2–3 месеца.

## Бързо (с Claude Code)

В тази папка пуснете Claude Code и напишете:

```
/update-data
```

или само за един раздел: `/update-data budget`. Подсказката е в `.claude/commands/update-data.md` —
Claude пуска скрипта, прилага промените от Евростат, проверява ръчните източници, обновява
текстовете „Накратко“ и началната страница и пуска тестовете.

## Ръчно

```bash
npm run update-data              # само проверка → data/update-report.md
npm run update-data -- --apply   # записва промените от Евростат в src/pages/*.js
npm test && npm run build
```

Отчетът има три части:

1. **Промени от Евростат** — ревизии на минали години и нови години. `--apply` ги записва сам,
   ако намери масива в кода; иначе пише „⚠ обновете ръчно“.
2. **Проблеми** — обикновено Евростат е сменил кодовете на набора. Скриптът показва
   допустимите стойности; добавете липсващия филтър в `scripts/sources.mjs`.
3. **За ръчна проверка** — източници без API (НСИ, МВР, ВСС, НОИ, Министерски съвет) с адрес,
   файлове в сайта, които зависят от тях, и кога излизат.

## Нова година

Когато се появят данни за нова година, тя трябва да се добави в `YEARS` (`src/lib/format.js`)
и всеки масив в `src/pages/*.js` и `src/data/oblasts.js` да се удължи с една стойност (`null` до
публикуването). `npm test` проверява, че дължините съвпадат.

## Нов показател от Евростат

1. Добавете го в `metrics` и `order` на страницата (вижте README.md).
2. Добавете ред в `EUROSTAT` в `scripts/sources.mjs` с набора и филтрите.
3. `npm run update-data` — ако филтърът е непълен, отчетът казва кои измерения липсват.

## Инфлация за „Отчети инфлацията“

Сумите в евро (`money: true` в описанието на показателя) могат да се покажат и в цени от последната година.
Индексът е `HICP_INDEX` в `src/lib/format.js` — Евростат, `prc_hicp_aind`, `geo=BG`, `coicop=CP00`, `unit=INX_A_AVG` (2015 = 100).
Когато добавите нова година, добавете и нейния индекс; последната година става базова автоматично.
