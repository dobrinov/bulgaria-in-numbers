# България в цифри

Сайт с официални данни за България от 2015 г. насам — население, доходи, здраве, области, икономика,
бюджет и дълг, данъци, администрация, сигурност, правосъдие и енергетика. Всяко число е от НСИ,
Евростат, МВР, НОИ, ВСС или Министерския съвет и има посочен източник.

## Стартиране

```bash
npm install
npm run dev      # локален сървър с презареждане
npm run build    # статичен сайт в dist/
npm run preview  # преглед на dist/
npm test         # проверки на данните
npm run update-data  # проверка за нови данни (вижте UPDATING.md)
```

Готовата папка `dist/` е статична и може да се публикува навсякъде (GitHub Pages, Netlify, Cloudflare Pages).

## Как е устроен

- **Без рамка** — Vite + чист JavaScript (ES модули). Страниците се рисуват като HTML низове.
- **Адреси** — `#/икономика` е `#/economy`; областта и годината са в адреса:
  `#/economy?region=17&year=2024`. Така всеки изглед може да се сподели.
- **Избраната област** се пази и в браузъра (`localStorage`), докато не я изчистите.

```
src/
  main.js                 маршрутизиране и обработка на действия (data-action)
  styles.css              всички стилове
  lib/format.js           години, числа по български, корелация
  lib/charts.js           SVG графики: линия, разсейване, ленти
  lib/state.js            състояние и адрес
  components/header.js    горна лента и меню „Раздели“
  components/regionMap.js карта на 28-те области + панел + плаваща лента
  components/sectionPage.js обща страница на раздел
  data/geo.js             граници на областите (Евростат GISCO, NUTS 3)
  data/oblasts.js         данни по области (последна година и редове 2015–2025)
  pages/registry.js       групи и страници (меню и начало)
  pages/<раздел>.js       съдържание и данни на всеки раздел
```

## Добавяне на показател

Всеки раздел е описание в `src/pages/<раздел>.js`. Нов показател се добавя в `metrics` и `order`:

```js
unemployment: {
  label: 'Безработица', d: 1, suffix: '%', good: 'down', pp: true,
  values: [10.1, 8.6, 7.2, 6.2, 5.2, 6.1, 5.2, 4.2, 4.3, 4.2, 3.5], // 2015–2025, null = няма данни
  sub: 'Коефициент на безработица, 15–74 г.', source: 'Евростат, une_rt_a',
  reg: (r) => ({ values: SERIES.unemp[r], cmp: [...] }), // по желание: стойности за област r
}
```

- `good`: `'up'` (по-високото е по-добро), `'down'` или `'none'` — определя цвета на промяната.
- `pp: true` — промяната се показва в процентни пунктове.
- `eu` — ред за ЕС-27; рисува се като пунктир.
- `reg(r)` — ако страницата има `map.drivesPage`, изборът на област заменя стойностите.

## Данни

Как се обновяват данните: [UPDATING.md](UPDATING.md) (или командата `/update-data` в Claude Code).

Данните са събрани от официалните публикации и API на Евростат; суровите файлове са в `data/raw/`.
Където данни за година още не са публикувани, стойността е `null` и сайтът го казва.
